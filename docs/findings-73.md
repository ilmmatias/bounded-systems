# 1. Finite phase mixtures

The necessary condition for finite forcing in `findings-72.md` is also
sufficient when the finitely many phases are themselves absolutely finitely
forcible.

Let

```math
\xi_1,\ldots,\xi_r
```

be distinct extremal central sectors, and assume each $\xi_a$ is absolutely
forced by finitely many pattern coordinates. Fix positive weights

```math
\lambda_a>0,
\qquad
\sum_{a=1}^r\lambda_a=1,
```

and define

```math
\mu
=
\sum_{a=1}^r\lambda_a\xi_a.
```

# 2. Forcing the phase support

For each phase choose a nonnegative polynomial forcing energy

```math
E_a(\eta)
```

in finitely many pattern coordinates such that

```math
E_a(\eta)=0
\quad\Longleftrightarrow\quad
\eta=\xi_a.
```

On the extremal boundary define

```math
P(\eta)
=
\prod_{a=1}^r E_a(\eta).
```

The function is nonnegative and vanishes exactly on

```math
\{\xi_1,\ldots,\xi_r\}.
```

By the boundary polynomial lift of `findings-70.md`, the condition

```math
\int P(\eta)\,d\nu(\eta)=0
```

is a finite ordinary DAG density constraint. It forces the ergodic
decomposition to be supported on the prescribed finite phase set.

# 3. Forcing the phase weights

A finite set of distinct extreme points in a simplex is affinely independent.
Otherwise two different convex combinations of those points would have the
same barycenter, contradicting uniqueness of the ergodic decomposition.

The complete pattern profiles of the $\xi_a$ therefore have affine rank
$r-1$. This rank is witnessed by finitely many pattern coordinates: there are
$g_1,\ldots,g_s$, with $s\geq r-1$, such that the vectors

```math
(g_1(\xi_a),\ldots,g_s(\xi_a))
```

are affinely independent. Prescribing

```math
\int g_j(\eta)\,d\nu(\eta)
=
\sum_{a=1}^r
\lambda_ag_j(\xi_a)
```

then fixes the weights uniquely.

## Theorem 1. Absolute forcing of finite phase mixtures

Every finite mixture of absolutely finitely forcible extremal central sectors
is absolutely finitely forcible in the full central DAG boundary.

Together with `findings-72.md`, this shows that, within the class generated by
known finitely forcible extremal sectors, finite absolute selection is
equivalent to finite extremal phase support.

# 4. Harmonic decomposition

Write $\mu_n^a$, $h_n^a$, and $U_n^a$ for the level profile, harmonic
function, and up transition of phase $a$. The mixture satisfies

```math
\mu_n(G)
=
\sum_a\lambda_a\mu_n^a(G),
```

and

```math
h_n(G)
=
\sum_a\lambda_ah_n^a(G).
```

For a positive-mass endpoint $G$, define the posterior phase weights

```math
\pi_n(a\mid G)
=
\frac{\lambda_a\mu_n^a(G)}{\mu_n(G)}
=
\frac{\lambda_ah_n^a(G)}{h_n(G)}.
```

## Proposition 2. Adaptive mixture transition

The reconstructed up transition is

```math
U_n^\mu(G,H)
=
\sum_{a=1}^r
\pi_n(a\mid G)U_n^a(G,H).
```

## Proof

Using the profile reconstruction formula,

```math
\begin{aligned}
\sum_a\pi_n(a\mid G)U_n^a(G,H)
&=
\sum_a
\frac{\lambda_a\mu_n^a(G)}{\mu_n(G)}
D_n(H,G)
\frac{\mu_{n+1}^a(H)}{\mu_n^a(G)}\\
&=
D_n(H,G)
\frac{\sum_a\lambda_a\mu_{n+1}^a(H)}{\mu_n(G)}\\
&=
U_n^\mu(G,H).
\end{aligned}
```

# 5. Posterior phase dynamics

Along an extension $G\to H$, Bayes' rule gives

```math
\pi_{n+1}(a\mid H)
=
\frac{
 \pi_n(a\mid G)U_n^a(G,H)
}{
 U_n^\mu(G,H)
}.
```

The vector $\pi_n$ is a bounded martingale with respect to the observed
endpoint filtration. It converges almost surely to the indicator of the
sampled extremal phase. Thus a finite phase mixture has an exact
finite-dimensional adaptive boundary state:

```math
\text{current endpoint }G
+
(r-1)\text{ posterior phase coordinates}.
```

The positive half-integer fluctuation spectrum holds conditionally inside each
phase. The only nondecaying component is the finite-valued phase variable.

# 6. Example

Take two stochastic source-sink sectors with common source mass $\theta$ and
distinct edge probabilities $r_1\neq r_2$. Each is absolutely forced by
`findings-69.md`. Their union is forced by the product of the two sector
energies. Once support is restricted to the two phases, the edge density

```math
2\theta(1-\theta)
\left(
 \lambda r_1+(1-\lambda)r_2
\right)
```

determines the mixture weight $\lambda$.

# 7. Terminal approximation obstruction

Absolute forcing of a central mixture does not imply that one deterministic
sequence of finite endpoints converges to that mixed profile. Homomorphism
densities of a finite endpoint are multiplicative on disjoint unions, and
every coordinatewise endpoint limit remains multiplicative. A genuinely
nonextremal mixture is not multiplicative.

The terminal route-counting construction must therefore mix phase-specific
endpoint ensembles rather than seek endpoints whose individual profiles
approximate the mixture. The corrected construction is given in
`findings-74.md`.

Exact rational calculations confirm affine phase-weight recovery and the
adaptive transition identity.
