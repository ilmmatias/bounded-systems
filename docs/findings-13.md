# 1. Why $\mathrm{Tor}^A(B,B)$ is not the right higher invariant

Recall

```math
A=\mathbb K[G],\qquad
B=A/I,
```

where $I$ is the route-collapse ideal.

One might study

```math
\mathrm{Tor}^A_n(B,B).
```

Its first group does recover

```math
\mathrm{Tor}^A_1(B,B)\cong I/I^2.
```

But path algebras are hereditary in the standard quiver setting, so their module homology vanishes above degree one. Thus $\mathrm{Tor}^A_n(B,B)$ can be zero for $n\ge2$ even though the route relations possess nontrivial compositions and dependencies.

The reason is structural: $A$ is the free path algebra. Resolving $B$ over the free algebra asks how complicated $B$ is as an $A$-module, not how route ambiguities interact internally.

The correct algebra is instead the associated graded route algebra.

# 2. The route-graded algebra

Define

```math
C=\mathrm{gr}_I A=
\bigoplus_{m\ge0}C_m,
```

where

```math
C_0=B,
\qquad
C_m=I^m/I^{m+1}\quad(m\ge1).
```

Its positive part is

```math
C_+=
\bigoplus_{m\ge1}C_m.
```

The integer $m$ is ambiguity order:

* $C_1=I/I^2$: one route ambiguity;
* $C_2=I^2/I^3$: products of two route ambiguities;
* $C_3=I^3/I^4$: products of three;
* and so forth.

This grading exists even when route equalities mix original path lengths. For instance, a shortcut relation

```math
e-p
```

may compare a length-one path with a length-three path, but it still has ambiguity order one.

Set

```math
N=C_1=I/I^2.
```

Because $I^m$ is generated by products of $m$ elements of $I$, multiplication gives surjections

```math
N^{\otimes_Bm}\twoheadrightarrow C_m.
```

Consequently, there is a canonical graded algebra surjection

```math
\pi:T_B(N)\twoheadrightarrow C.
```

Let

```math
S=\ker\pi.
```

So:

```math
S=\text{all multiplicative relations among first-order route ambiguities}.
```

# 3. The canonical route-bar complex

Since

```math
C\longrightarrow B=C/C_+
```

is canonically augmented, define the reduced bar groups

```math
\mathsf B_n^{\mathrm{rt}}(G)=
\underbrace{
C_+\otimes_B\cdots\otimes_B C_+
}_{n\text{ factors}}
\qquad(n\ge1),
```

and

```math
\mathsf B_0^{\mathrm{rt}}(G)=B.
```

Write a simple tensor as

```math
[x_1|x_2|\cdots|x_n].
```

Define

```math
d_n[x_1|\cdots|x_n]=
\sum_{i=1}^{n-1}
(-1)^{i-1}
[x_1|\cdots|x_ix_{i+1}|\cdots|x_n].
```

For example,

```math
d_2[x|y]=xy,
```

and

```math
d_3[x|y|z]=
[xy|z]-[x|yz].
```

Associativity gives

```math
d_{n-1}d_n=0.
```

This is the standard reduced bar mechanism: neighboring factors are composed, while the alternating signs make the different ways of composing cancel. Bar resolutions are the canonical large resolutions used for associative algebras; quiver-with-relations theory often replaces them with smaller equivalent resolutions for calculation.

Define the route-syzygy homology

```math
H_n^{\mathrm{rt}}(G)=
H_n\bigl(\mathsf B_\bullet^{\mathrm{rt}}(G)\bigr).
```

For infinite node sets, all tensor products and equations can be read endpoint-corner by endpoint-corner. Every algebraic chain contains only finitely many terms and therefore lies inside a finite sum of node-idempotent corners.

# 4. The bigrading

Every factor $x_i$ has an ambiguity degree

```math
\deg_I(x_i)=m_i\ge1.
```

Define total ambiguity degree

```math
m=m_1+\cdots+m_n.
```

Then

```math
\mathsf B_{n,m}^{\mathrm{rt}}=
\bigoplus_{\substack{
m_1+\cdots+m_n=m\\
m_i\ge1
}}
C_{m_1}\otimes_B\cdots\otimes_B C_{m_n}.
```

The differential merges two adjacent factors and therefore preserves total ambiguity order:

```math
d:
\mathsf B_{n,m}^{\mathrm{rt}}
\longrightarrow
\mathsf B_{n-1,m}^{\mathrm{rt}}.
```

Hence

```math
H_n^{\mathrm{rt}}(G)=
\bigoplus_{m\ge n}
H_{n,m}^{\mathrm{rt}}(G).
```

There are now two independent degrees:

```math
\begin{array}{ccl}
n&=&\text{homological syzygy level},\\
m&=&\text{total number of ambiguity factors}.
\end{array}
```

Since every bar factor has degree at least one,

```math
H_{n,m}^{\mathrm{rt}}=0
\qquad(n>m).
```

This distinction corrects an earlier conflation:

* $I^m/I^{m+1}$ is actual $m$-fold ambiguity;
* $H_{n,m}^{\mathrm{rt}}$ is an $n$-th order dependency among ambiguity factorizations of total order $m$.

# 5. First homology

At bar degree one,

```math
\mathsf B_1^{\mathrm{rt}}=C_+.
```

The image of $d_2$ is

```math
C_+^2=
\bigoplus_{m\ge2}C_m,
```

because $C$ is generated by $C_1=N$.

Therefore

```math
H_1^{\mathrm{rt}}=
C_+/C_+^2
\cong C_1.
```

Thus

```math
H_{1,1}^{\mathrm{rt}}(G)
\cong I/I^2,
```

while

```math
H_{1,m}^{\mathrm{rt}}(G)=0
\qquad(m>1).
```

So first homology is precisely the space of independent first-order route ambiguities.

It contains classes arising from:

* parallel channels;
* diamonds;
* longer reconverging routes;
* shortcut-versus-composite discrepancies.

# 6. Second homology

At total ambiguity degree $m$,

```math
\mathsf B_{2,m}^{\mathrm{rt}}=
\bigoplus_{\substack{a+b=m\\a,b\ge1}}
C_a\otimes_BC_b.
```

The differential is multiplication:

```math
\mu_m:
\mathsf B_{2,m}^{\mathrm{rt}}
\longrightarrow C_m.
```

Degree-three boundaries identify the two associative ways of composing three factors. Explicitly,

```math
d_3[x|y|z]=
[xy|z]-[x|yz].
```

Hence

```math
H_{2,m}^{\mathrm{rt}}=
\frac{
\ker\!\left(
\displaystyle
\bigoplus_{a+b=m}C_a\otimes_BC_b
\xrightarrow{\mu_m}
C_m
\right)
}{
\mathrm{span}
\{
[xy|z]-[x|yz]:
\deg x+\deg y+\deg z=m
\}
}.
```

This is the first genuine syzygy group.

It records linear dependencies among two-stage ambiguity factorizations, after treating mere reassociation as trivial.

## Quadratic case

For $m=2$, no three-factor chain can have total degree two. Therefore there are no incoming degree-three boundaries:

```math
H_{2,2}^{\mathrm{rt}}=
\ker\!\left(
N\otimes_BN
\longrightarrow
I^2/I^3
\right).
```

This is especially transparent:

```math
H_{2,2}^{\mathrm{rt}}=
\text{quadratic relations among first-order route defects}.
```

# 7. Relation to the tensor-presentation ideal

Recall

```math
T=T_B(N)
```

and

```math
S=\ker(T\to C).
```

The positive ideal of $T$ is

```math
T_+=
\bigoplus_{m\ge1}N^{\otimes_Bm}.
```

The independent relation module is

```math
S_{\mathrm{ind}}=
S/(T_+S+ST_+).
```

Multiplying a relation on the left or right by further ambiguity generators does not create a new independent relation; it merely places an existing relation into a larger context.

The standard bar-presentation identification gives

```math
H_2^{\mathrm{rt}}(G)
\cong
S/(T_+S+ST_+).
```

Thus the earlier object $S$ should be called the route-relation ideal, while its indecomposable quotient—or equivalently $H_2^{\mathrm{rt}}$—is the space of independent relations among route ambiguities.

# 8. Third and higher homology

Third homology consists of cycles

```math
\sum_j[x_j|y_j|z_j]
```

such that

```math
\sum_j
\bigl(
[x_jy_j|z_j]-[x_j|y_jz_j]
\bigr)=0,
```

modulo boundaries coming from four-factor expressions.

Therefore:

```math
H_3^{\mathrm{rt}}=
\text{relations among the independent relations in }H_2^{\mathrm{rt}}.
```

Similarly,

```math
H_4^{\mathrm{rt}}
```

measures relations among those third-level dependencies, and so on.

This gives the intended hierarchy:

```math
\begin{aligned}
H_1^{\mathrm{rt}}
&:\text{primitive ambiguity classes},\\
H_2^{\mathrm{rt}}
&:\text{relations among ambiguity compositions},\\
H_3^{\mathrm{rt}}
&:\text{relations among those relations},\\
H_n^{\mathrm{rt}}
&:\text{(n)-th route syzygies}.
\end{aligned}
```

# 9. A single diamond

Suppose there are two paths

```math
p_0,p_1:u\to v
```

and let

```math
r=p_1-p_0.
```

Its class

```math
\bar r\in N
```

is nonzero.

Since

```math
\bar r\in e_vNe_u
```

and $u\ne v$, it cannot be tensored composably with itself:

```math
\bar r\otimes_B\bar r=0.
```

If this is the only ambiguity sector, then

```math
N\otimes_BN=0.
```

Consequently,

```math
H_1^{\mathrm{rt}}\cong\mathbb K\bar r,
```

while

```math
H_n^{\mathrm{rt}}=0
\qquad(n\ge2).
```

A lone diamond creates one independent route ambiguity but no higher dependency.

# 10. Two consecutive diamonds

Suppose

```math
p_0,p_1:u\to w
```

give

```math
r=p_1-p_0,
```

and

```math
q_0,q_1:w\to v
```

give

```math
s=q_1-q_0.
```

Then

```math
\bar s\otimes_B\bar r
```

is composable.

Its bar differential is

```math
d_2[\bar s|\bar r]=
\bar s\bar r.
```

Expanding in the original path algebra,

```math
sr=
q_1p_1-q_1p_0-q_0p_1+q_0p_0.
```

If this class is nonzero in

```math
I^2/I^3,
```

then

```math
[\bar s|\bar r]
```

is not a cycle.

Thus:

```math
\bar s\bar r\in I^2/I^3
```

is actual second-order ambiguity, not a second syzygy.

A second syzygy exists only when two-factor ambiguity expressions satisfy a dependency.

For example, if

```math
\bar s\bar r=
\bar y\bar x
```

in $I^2/I^3$, then

```math
[\bar s|\bar r]-[\bar y|\bar x]
```

is a quadratic bar cycle.

It represents two different ambiguity factorizations producing the same second-order defect.

# 11. Cubic coherence

At total ambiguity degree three,

```math
\mathsf B_{3,3}^{\mathrm{rt}}=
N\otimes_BN\otimes_BN.
```

There is no four-factor group of total degree three, so

```math
H_{3,3}^{\mathrm{rt}}=
\ker\!\left[
N^{\otimes_B3}
\longrightarrow
(C_2\otimes_BN)\oplus(N\otimes_BC_2)
\right],
```

where

```math
x\otimes y\otimes z
\longmapsto
xy\otimes z-x\otimes yz.
```

A class survives precisely when the two adjacent ways of composing its ambiguity factors cancel in a nontrivial linear combination.

This is the first level that can detect coherence among quadratic route relations.

# 12. Endpoint decomposition

Every bar chain has fixed external endpoints.

For nodes $u,v$,

```math
e_v\mathsf B_{n,m}^{\mathrm{rt}}e_u
```

is spanned by composable ambiguity chains

```math
u=u_0
\rightsquigarrow u_1
\rightsquigarrow\cdots
\rightsquigarrow u_n=v,
```

where the $i$-th factor lies in some

```math
e_{u_i}C_{m_i}e_{u_{i-1}}
```

and

```math
m_1+\cdots+m_n=m.
```

The differential preserves the external endpoints. Hence

```math
H_{n,m}^{\mathrm{rt}}=
\bigoplus_{u,v}
e_vH_{n,m}^{\mathrm{rt}}e_u.
```

This makes the invariant fully route-localized:

```math
e_vH_{n,m}^{\mathrm{rt}}e_u
```

measures $n$-th syzygies of total ambiguity order $m$ between the particular endpoint pair $(u,v)$.

# 13. Transfinite rank support

Suppose past ranks exist.

An element of

```math
e_vC_me_u
```

is represented by a product of $m$ positive route defects. Therefore it advances past rank by at least $m$:

```math
\rho_-(u)+m\le\rho_-(v).
```

The same applies to every bar chain of total ambiguity degree $m$. Consequently,

```math
\Delta^-_\beta
H_{n,m}^{\mathrm{rt}}
\Delta^-_\alpha
=0
\quad\text{unless}\quad
\alpha+m\le\beta.
```

Dually,

```math
\Delta^+_\beta
H_{n,m}^{\mathrm{rt}}
\Delta^+_\alpha
=0
\quad\text{unless}\quad
\beta+m\le\alpha.
```

So route syzygies themselves have transfinite triangular support.

They cannot occur between ordinal layers too close to accommodate their total ambiguity order.

# 14. A canonical invariant family

Over a field, define the endpoint-rank Betti cardinals

```math
\beta_{n,m}(v,u)=
\dim_{\mathbb K}
e_vH_{n,m}^{\mathrm{rt}}e_u.
```

At the ordinal-layer level,

```math
\beta_{n,m}^-(\beta,\alpha)=
\dim_{\mathbb K}
\Delta^-_\beta
H_{n,m}^{\mathrm{rt}}
\Delta^-_\alpha.
```

These may be finite or infinite cardinals.

One can package them formally as

```math
\mathcal P_{v,u}(s,t)=
\sum_{n\ge1}
\sum_{m\ge n}
\beta_{n,m}(v,u)s^nt^m.
```

Here:

* $s$ tracks syzygy level;
* $t$ tracks ambiguity order.

This two-variable series records route dependence by syzygy level and ambiguity order.

# 15. Coefficient-free version

Choosing $\mathbb C$ is useful for Hilbert and spectral representations, but the algebraic construction can begin over

```math
\mathbb Z.
```

Define

```math
A_{\mathbb Z},
\qquad
B_{\mathbb Z},
\qquad
I_{\mathbb Z},
\qquad
H_{n,m}^{\mathrm{rt}}(G;\mathbb Z).
```

Then a field-valued version is obtained by scalar extension, subject to the usual possible torsion effects.

Thus the most coefficient-neutral invariant is

```math
H_{n,m}^{\mathrm{rt}}(G;\mathbb Z).
```

Torsion, should it occur, would contain information invisible to vector-space dimensions over a field.

# 16. Algebraic rather than analytic

Because the bar complex uses finite algebraic sums, it is independent of:

* bounded degree;
* countability;
* measure;
* Hilbert norm;
* convergence convention.

The infinite-route result established earlier shows that route-collapse coefficient summation can become unbounded in Fock norm.

Therefore there is no automatic canonical Hilbert completion of the route-syzygy complex.

The correct order is:

```math
\text{algebraic route homology first;}
\quad
\text{analytic completions only when convergence permits}.
```
