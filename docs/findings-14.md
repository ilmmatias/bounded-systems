# 1. Canonical route-difference symbols

For two paths with identical endpoints,

```math
p,q:u\to v,
```

write

```math
\delta(p,q)=p-q\in I.
```

These symbols satisfy

```math
\delta(p,p)=0,
\qquad
\delta(p,q)=-\delta(q,p),
\qquad
\delta(p,q)+\delta(q,r)=\delta(p,r).
```

For a fixed endpoint pair, these relations give exactly the augmentation kernel

```math
I_{v,u}=
\left\lbrace \sum_{p:u\to v}c_pp: \sum_pc_p=0 \right\rbrace.
```

The ideal $I$ can be described without choosing a preferred route:

```math
I=\mathrm{span}
\{\delta(p,q):s(p)=s(q),\ r(p)=r(q)\}.
```

Choosing one reference route per endpoint pair would give a smaller basis, but it would not be canonical.

# 2. Rectangle defects

Suppose two route ambiguities are composable, with

```math
p_0,p_1:u\to w,
\qquad
q_0,q_1:w\to v.
```

Set $r$ by

```math
r=p_1-p_0,
\qquad
s=q_1-q_0.
```

Their product is

```math
sr=
q_1p_1-q_1p_0-q_0p_1+q_0p_0.
```

The rectangle defect is the signed sum around four complete routes:

```math
\begin{matrix}
q_1p_1 &\longleftrightarrow& q_1p_0\\
\updownarrow &&\updownarrow\\
q_0p_1 &\longleftrightarrow& q_0p_0.
\end{matrix}
```

It belongs to $I^2$.

Consequently, at first ambiguity order,

```math
C_1=I/I^2,
```

The rectangle vanishes:

```math
q_1p_1-q_1p_0
\equiv
q_0p_1-q_0p_0
\pmod{I^2}.
```

The equality says that either choice of the second route transports the first ambiguity to the same first-order class.

Similarly,

```math
q_1p_1-q_0p_1
\equiv
q_1p_0-q_0p_0
\pmod{I^2}.
```

But at second order,

```math
C_2=I^2/I^3,
```

The rectangle itself may survive as a nonzero interaction:

```math
[sr]\in C_2.
```

The same alternating square has two interpretations:

```math
\begin{aligned}
\text{in }C_1:&\quad \text{a relation among transported ambiguities},\\
\text{in }C_2:&\quad \text{an actual second-order ambiguity}.
\end{aligned}
```

# 3. Higher route-choice boxes

For $1\le i\le m$, let $p_i^0,p_i^1:v_{i-1}\to v_i$ be composable pairs of alternative routes.

Define the $m$-box defect

```math
\Box(p_1^0,p_1^1;\ldots;p_m^0,p_m^1)=
(p_m^1-p_m^0)\cdots(p_1^1-p_1^0).
```

Expanding gives

```math
\Box=
\sum_{\epsilon\in\{0,1\}^m}
(-1)^{m-|\epsilon|}
p_m^{\epsilon_m}\cdots p_1^{\epsilon_1}.
```

It is the alternating sum of the $2^m$ complete routes formed by independently choosing one of two possibilities at each ambiguity sector.

For $m=1$ this is a route difference, for $m=2$ a four-route rectangle, for $m=3$ an eight-route cube, and for $m=4$ a sixteen-route hypercube. Since $I$ is spanned by route differences,

```math
I^m=
\operatorname{span}\{\text{$m$-box defects}\}.
```

Consequently, $C_m=I^m/I^{m+1}$ is the space of $m$-choice boxes modulo the linear combinations generated by $(m+1)$-choice boxes.

No labels, weights, or preferred routes are required.

# 4. The reachability algebra acts by path context

Recall

```math
B=A/I.
```

An element

```math
\varepsilon_{b,a}\in B
```

represents the unique route-insensitive morphism from $a$ to $b$.

To act on a class

```math
[x]\in C_m,
```

choose any actual path $t:a\to b$ representing $\varepsilon_{b,a}$, and concatenate it with $x$.

The result is independent of the chosen path modulo $I^{m+1}$.

Indeed, if $t'$ is another representative, then

```math
t-t'\in I.
```

Since $x\in I^m$,

```math
(t-t')x\in I^{m+1}.
```

Hence the two choices determine the same class:

```math
[tx]=[t'x]\in C_m,
```

so $B$ acts canonically on every $C_m$ even though no canonical route representative of a reachability relation exists.

# 5. Combinatorial meaning of tensoring over $B$

Suppose $X\in C_a$ and $Y\in C_b$, with a reachability context $c\in B$ between them.

The balanced tensor product imposes

```math
(Xc)\otimes_B Y=
X\otimes_B(cY).
```

A route-insensitive path segment between two ambiguity boxes may be attached to either adjacent box.

Therefore a bar chain does not remember exactly where ordinary, nonambiguous path context was cut between its ambiguity blocks.

It remembers only the decomposition into ambiguity factors.

Tensor products therefore retain ambiguity blocks but not the exact placement of ordinary path context.

# 6. The combinatorial ambiguity complex

For total ambiguity order $m$ and bar degree $n$, define

```math
\mathfrak C_{n,m}(G)=
\bigoplus_{\substack{
m_1+\cdots+m_n=m\\
m_i\ge1
}}
C_{m_n}\otimes_B\cdots\otimes_B C_{m_1}.
```

A generator can be pictured as

```math
[X_1|X_2|\cdots|X_n],
```

where $X_i$ is an $m_i$-box class; the boxes are composable; $\sum_i m_i=m$; and route-insensitive contexts may slide across bar separators.

Define the differential by merging adjacent boxes:

```math
d[X_1|\cdots|X_n]=
\sum_{i=1}^{n-1}
(-1)^{i-1}
[X_1|\cdots|X_{i+1}X_i|\cdots|X_n].
```

The merged block has ambiguity order

```math
m_i+m_{i+1}.
```

Associativity of path concatenation gives

```math
d^2=0.
```

The resulting complex is the reduced relative bar construction for the augmentation $C\to B$, written in route-choice language.

# 7. Low-degree form

## Degree $(1,1)$

The degree $(1,1)$ component is

```math
\mathfrak C_{1,1}=C_1=I/I^2.
```

This gives

```math
H_{1,1}^{\mathrm{rt}}=I/I^2.
```

These are first-order route ambiguities, including their path-context transports.

## Degree $(2,2)$

The degree $(2,2)$ component is

```math
\mathfrak C_{2,2}=
C_1\otimes_BC_1.
```

The differential is

```math
d_2:
C_1\otimes_BC_1\to C_2,
\qquad
[s|r]\mapsto[sr].
```

This gives

```math
H_{2,2}^{\mathrm{rt}}=
\ker\!\left(
C_1\otimes_BC_1
\longrightarrow C_2
\right).
```

A pair of composable ambiguities is not automatically a second syzygy.

It is a second syzygy only when its associated rectangle vanishes in $I^2/I^3$, or when a linear combination of rectangles cancels.

## Degree $(3,3)$

The degree $(3,3)$ component is

```math
\mathfrak C_{3,3}=
C_1\otimes_BC_1\otimes_BC_1.
```

For composable $r,s,t$,

```math
d_3[t|s|r]=
[ts|r]-[t|sr].
```

The boundary compares the two groupings of the same three ambiguity choices.

A third homology class requires a nontrivial combination whose adjacent mergers cancel, modulo four-block boundaries.

# 8. A single diamond

Suppose exactly two routes connect $u$ to $v$:

```math
p_0,p_1:u\to v,
```

and assume no other route ambiguity composes with this one.

Set $r$ by

```math
r=p_1-p_0.
```

It follows that

```math
I=\mathbb K r,
\qquad
I^2=0.
```

The resulting isomorphism is

```math
C_1\cong\mathbb K r,
\qquad
C_m=0\quad(m\ge2).
```

Also,

```math
C_1\otimes_BC_1=0,
```

because $r$ cannot be composed with itself in an acyclic system.

```math
H_{1,1}^{\mathrm{rt}}\cong\mathbb K,
\qquad
H_{n,m}^{\mathrm{rt}}=0
\quad(n\ge2).
```

The same result applies to:

* two parallel primitive channels;
* a basic diamond;
* a single shortcut-versus-composite relation.

Their path lengths differ, but their ambiguity complex has the same simplest homological shape.

The path-length bifiltration distinguishes those cases.

# 9. Two consecutive binary diamonds

Suppose there are two route pairs

```math
p_0,p_1:u\to w,
```

and

```math
q_0,q_1:w\to v.
```

Set the two route differences to

```math
r=p_1-p_0,
\qquad
s=q_1-q_0.
```

There are four complete routes from $u$ to $v$:

```math
q_0p_0,\quad q_0p_1,\quad q_1p_0,\quad q_1p_1.
```

Their second-order interaction is

```math
sr=
q_1p_1-q_1p_0-q_0p_1+q_0p_0.
```

Assuming no further ambiguity sector makes this element belong to $I^3$,

```math
[sr]\ne0\in C_2.
```

This gives

```math
d_2[s|r]=[sr]\ne0,
```

so

```math
[s|r]
```

is not a second-homology class.

two consecutive diamonds create second-order ambiguity,

but not necessarily a second syzygy.

The local irreducible module

```math
\mathcal R=I/(JI+IJ)
```

contains the two elementary diamonds.

By contrast,

```math
C_1=I/I^2
```

also contains their route-context transports, such as

```math
q_0r,
\qquad
sp_0,
```

in the larger endpoint corner $u\to v$.

```math
\mathcal R\text{ counts local ambiguity sources, while }C_1
\text{ records their first-order effects throughout the system}.
```

# 10. Quadratic syzygies

Suppose there are several composable pairs of first-order ambiguity classes:

```math
(s_j,r_j).
```

A quadratic bar cycle has the form

```math
Z=\sum_j c_j[s_j|r_j]
```

with

```math
d_2Z=
\sum_jc_j[s_jr_j]=
0
\quad\text{in }C_2.
```

Equivalently,

```math
\sum_jc_js_jr_j\in I^3.
```

a genuine quadratic syzygy is a dependency among rectangle defects.

It does not arise merely because multiple route choices exist.

Grids, overlapping diamonds, and higher-dimensional route-choice diagrams provide natural candidates, but each candidate must still be checked:

1. does its alternating rectangle combination vanish modulo $I^3$?
2. is it already a bar boundary?
3. is the cancellation only an artifact of moving reachability context through the $B$-balanced tensor?

A visible geometric cube therefore need not produce nonzero homology.

# 11. Cube interpretation

An $m$-box has $m$ ambiguity coordinates.

A bar separator partitions those coordinates into consecutive blocks.

For example, a three-choice cube can appear in any of the forms

```math
[1|1|1],
\qquad
[2|1],
\qquad
[1|2],
\qquad
[3],
```

where the entries are ambiguity orders and the separators record the chosen block decomposition.

The differential removes one separator:

```math
[1|1|1]
\longmapsto
[2|1]-[1|2].
```

It follows that

```math
[2|1]
\quad\text{and}\quad
[1|2]
```

both map to the same three-box, with opposite signs.

Thus the bar differential records compatibility among different ways of grouping the ambiguity coordinates.

The nontrivial homology appears only when the actual route algebra introduces identifications beyond ordinary associativity.

# 12. Finite computation inside one chosen system

For a finite system, or finite ordinal-rank band, the complex can be constructed by linear algebra:

1. Enumerate all finite paths in the selected subsystem.
2. Group them by source and target.
3. Build $I$ from route differences.
4. Generate $I^2,I^3,\ldots$ using route-choice boxes.
5. Form $C_m=I^m/I^{m+1}$.
6. Compute the left and right $B$-actions by concatenating any path representative of each reachability arrow.
7. Form the balanced tensor products over $B$.
8. Build the merge differentials.
9. Compute kernels and images endpoint by endpoint.

The calculation concerns the internal ambiguity structure of one system or rank truncation, not an exhaustive classification by graph size.

# 13. Infinite systems

The algebraic construction remains valid without countability or local finiteness: every route difference uses two finite paths, every box has finitely many coordinates, every bar chain has finitely many factors, and every differential is a finite alternating sum.

No infinite scalar summation is required.

Computational stabilization may fail: increasing finite path-supported truncations need not reveal the final homology at any predetermined finite stage.

Therefore a finite calculation should be described as the homology of a specified rank or path-supported truncation unless an independent theorem proves stabilization.
