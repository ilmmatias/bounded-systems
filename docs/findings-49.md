# 1. The fluctuation operator to be estimated

From the configuration recursion

[
x_{n+1}=x_n+\frac1{n+1}F_n,
]

the hydrodynamic drift is

[
b(x)=\lim\mathbb E[F_n\mid x_n=x].
]

At a fixed profile

[
b(x_\ast)=0,
]

define

[
\boxed{
J=Db(x_\ast).
}
]

The central-limit normalization contributes an additional one-half identity, so the positive relaxation operator is

[
\boxed{
B=-\left(J+\frac12I\right).
}
]

The finite-data task was therefore not to fit an arbitrary spectral law, but to estimate the derivative of the exact sampled drift field.

# 2. Duality reduction

The six raw profile coordinates obey exact or asymptotic order-duality relations. Direct regression in the unreduced coordinates contains null or nearly null covariance directions.

The analysis therefore separated:

* duality-even tangent coordinates;
* the normal direction to the fixed-profile constraint surface;
* a duality-odd coordinate;
* exact redundant directions removed by pseudoinverse thresholding.

This reduction turned the apparent pair of fixed (-1/2) relaxation values from the earliest regression into understood zero-Jacobian directions generated by redundant coordinates, rather than physical slow modes.

# 3. Large trajectory samples

The main Jacobian extraction used:

* 100,000 exact trajectories with terminal size (N=128);
* 50,000 exact trajectories with terminal size (N=256);
* checkpoint levels in the asymptotic bulk, including (96,112,120,126) and (192,224,240,254).

At each checkpoint, the scaled increment

[
F=(n+1)\Delta x
]

was regressed against profile displacement from the local mean.

Bootstrap resampling retained trajectory pairing across checkpoints.

# 4. First stable spectrum

The initial reduced estimate of

[
\widehat B=-\left(\widehat J+\frac12I\right)
]

showed:

* three relaxation eigenvalues in a near-degenerate band around (1.4-1.6);
* one separated relaxation eigenvalue around (2.5);
* all eigenvalues in the open right half-plane;
* agreement between terminal sizes 128 and 256 within the bootstrap uncertainty.

Thus no neutral or destabilizing mode was observed in this dictionary.

The near-degenerate triplet made individual eigenvectors less stable than the invariant subspace and eigenvalue cluster. The correct finite claim is therefore spectral-subspace stability, not a precisely identified basis inside the triplet.

# 5. Anisotropic normal and odd sectors

A symmetry-adapted audit isolated two especially clean Jacobian directions.

The normal direction had

[
\boxed{
J_{\mathrm{normal}}\approx-3,
}
]

while the odd/antisymmetric direction had

[
\boxed{
J_{\mathrm{odd}}\approx-2.
}
]

The corresponding fluctuation relaxation values are

[
\boxed{
B_{\mathrm{normal}}\approx\frac52,
\qquad
B_{\mathrm{odd}}\approx\frac32.
}
]

These values explain the separated eigenvalue near (2.5) and part of the lower cluster near (1.5).

# 7. Multistep semigroup validation

A one-step regression can create misleading eigenvalues if the projected process is not approximately closed. Therefore the same trajectories were used to estimate effective maps across multiple checkpoint intervals.

For terminal 128, examples included

[
96\to112,
96\to120,
96\to126,
112\to120,
112\to126,
120\to126.
]

For terminal 256, the corresponding doubled intervals were analyzed.

Across all 12 pairs:

[
J_{\mathrm{normal}}
\approx
-3.05\text{ to }-2.98,
]

and

[
J_{\mathrm{odd}}
\approx
-2.07\text{ to }-2.04
]

apart from ordinary sampling variation.

The predictive (R^2) behaved as expected:

* approximately 0.89-0.91 for the shortest late intervals;
* approximately 0.73 for moderate intervals;
* approximately 0.57 for the longest interval.

The decline with interval length reflects nonlinear and stochastic accumulation, while the generator rates remain stable.

# 8. Exact reduced surrogate

A finite-size surrogate transfer calculation at

[
96\to112
]

gave the exact or high-precision rates

[
\boxed{
J_{\mathrm{normal}}=-3,
\qquad
J_{\mathrm{edge}}=-2,
\qquad
J_{\mathrm{mixed}}=-2.0460410676.
}
]

Comparing the surrogate with all 12 empirical semigroup pairs produced

[
\boxed{
\text{mean matrix defect}=0.0236841,
}
]

and

[
\boxed{
\text{median matrix defect}=0.0199061.
}
]

Thus the finite sampled transfer maps were within a few percent of the reduced analytic surrogate.

# 9. Noise-floor comparison

To determine whether the observed matrix discrepancy was meaningful, the 100,000-sample terminal-128 data were repeatedly subsampled to 50,000 trajectories.

Across 200 replicates, the empirical matrix-defect distribution had

[
\boxed{
q_{0.50}=0.0352025,
\qquad
q_{0.975}=0.0705461.
}
]

The exact-versus-surrogate discrepancy near (0.02-0.024) was below the median same-law sampling defect. Therefore no statistically resolved disagreement with the surrogate transfer matrix was detected at that sample size.

# 10. Eigenobservable validation

Rather than comparing only full matrices, the analysis tested the predicted eigenobservables directly across every checkpoint pair.

The errors in the edge, mixed-even, mixed-odd, and normal observables were generally of order

[
10^{-3}\text{ to }10^{-2}.
]

The largest listed normal-observable error was approximately

[
-0.0111,
]

while most errors were several times smaller.

Every pair passed. This is stronger than a favorable eigenvalue fit because it checks the action on predeclared observables.

# 11. Interpretation as a genuine fluctuation flow

The combined evidence supports the following chain:

[
\boxed{
\text{large-size profile reaches }x_\ast,
}
]

[
\boxed{
\text{scaled drift linearizes with stable }J,
}
]

[
\boxed{
\text{multistep maps follow one semigroup to finite accuracy,}
}
]

and

[
\boxed{
B=-\left(J+\frac12I\right)
\text{ has a positive spectral gap.}
}
]

The smallest observed relaxation rate is near

[
\boxed{\frac32},
]

well separated from zero.

# 12. What was ruled out at this dictionary level

The data disfavor:

* a continuum of fixed-profile moduli;
* an unstable configuration direction;
* a neutral fluctuation mode hidden in the duality-reduced first dictionary;
* a purely one-step regression artifact;
* large terminal-size drift of the principal spectrum between (N=128) and (N=256).

They do not rule out a slower mode that exists only in a substantially richer profile dictionary.
