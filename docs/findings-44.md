# 1. Canonical coordinates without choosing arbitrary features

At refinement depth $r$, a node has the normalized profile

```math
x_{G,r}(u)=
\frac1{|V|}
\sum_{v\in V}
\delta_{\left(z_r(u,v),z_r(v,u)\right)}
\in
\mathcal Y_r=
\mathcal P(\mathcal Z_r^2).
```

Instead of selecting ad hoc numerical graph statistics, take any continuous
test function

```math
\varphi\in C(\mathcal Z_r^2)
```

and define the linear cylinder observable

```math
F_\varphi(x)=
\int_{\mathcal Z_r^2}\varphi(\zeta)\,x(d\zeta).
```

For a finite DAG,

```math
F_\varphi(x_{G,r}(u))=
\frac1{|V|}
\sum_{v\in V}
\varphi\!\left(
z_r(u,v),z_r(v,u)
\right).
```

Products of these observables give polynomial cylinders:

```math
F(x)=
P\left(
F_{\varphi_1}(x),\ldots,F_{\varphi_d}(x)
\right).
```

The algebra generated by all $F_\varphi$:

* contains constants;
* is closed under multiplication;
* separates distinct probability measures in $\mathcal Y_r$.

Therefore, by Stone-Weierstrass,

```math
\overline{\operatorname{Alg}\{F_\varphi\}}=
C(\mathcal Y_r).
```

Cylinder observables form a dense canonical core for the continuum generator.

For computation, choose a countable dense dictionary

```math
\varphi_1,\varphi_2,\ldots
```

and retain more cylinders. The final operator is independent of the chosen
dense enumeration.

# 2. Exact finite-horizon route kernel

Let $A$ be the adjacency matrix, including parallel-edge multiplicities.

Define the forward route-count vectors

```math
r_0=\mathbf1,
\qquad
r_k=Ar_{k-1}=A^k\mathbf1,
```

and the backward route-count vectors

```math
\ell_0=\mathbf1,
\qquad
\ell_j=A^\mathsf T\ell_{j-1}=
(A^\mathsf T)^j\mathbf1.
```

Thus $r_k(v)$ counts the length-$k$ routes starting at $v$, whereas
$\ell_j(v)$ counts the length-$j$ routes ending at $v$.

The total number of length-$p$ routes is

```math
T_p=\mathbf1^\mathsf TA^p\mathbf1
=\mathbf1^\mathsf Tr_p.
```

For $k\ge1$, the exact remaining-horizon transition kernel is

```math
P_k(v,w)=
\frac{A_{vw}r_{k-1}(w)}{r_k(v)}
```

when $r_k(v)>0$.

Normalization follows because

```math
\sum_wA_{vw}r_{k-1}(w)=r_k(v).
```

No stochastic law was independently chosen; $P_k$ uniformly counts all
resolved routes with $k$ remaining edges.

# 3. Exact edge-flow matrices

Under the uniform measure on all length-$p$ routes, define

```math
\mathsf F_{p,j}=
\frac1{T_p}
\mathrm{diag}(\ell_j)\,
A\,
\mathrm{diag}(r_{p-j-1})
```

for

```math
0\le j<p.
```

Its entries are

```math
\mathsf F_{p,j}(v,w)=
\frac{
\ell_j(v)A_{vw}r_{p-j-1}(w)
}{
T_p
}.
```

This gives

```math
\mathsf F_{p,j}(v,w)=
\Pr(
X_j=v,\ X_{j+1}=w
)
```

in the uniform length-$p$ route ensemble.

It satisfies

```math
\sum_{v,w}\mathsf F_{p,j}(v,w)=1.
```

Average over route position:

```math
\overline{\mathsf F}_p=
\frac1p
\sum_{j=0}^{p-1}
\mathsf F_{p,j}.
```

The matrix contains the route-weighted one-step statistics needed for the
coefficient calculations.

# 4. Finite-dimensional cylinder coordinates

Choose $d$ cylinder tests

```math
\varphi_1,\ldots,\varphi_d.
```

Associate to every node $v$ the vector

```math
X_r(v)=
\begin{pmatrix}
F_{\varphi_1}(x_{G,r}(v))\\
\vdots\\
F_{\varphi_d}(x_{G,r}(v))
\end{pmatrix}
\in\mathbb R^d.
```

Let $X$ denote the $n\times d$ matrix whose $v$-th row is $X_r(v)^\mathsf T$.

For an edge $v\to w$, the coordinate jump is

```math
\Delta X_{vw}=X_r(w)-X_r(v).
```

The route-averaged drift per primitive edge is

```math
m_{p,r}=
\sum_{v,w}
\overline{\mathsf F}_p(v,w)
\Delta X_{vw}.
```

Define the outgoing and incoming route-flow marginals

```math
d_{\mathrm{out}}=
\overline{\mathsf F}_p\mathbf1,
```

and

```math
d_{\mathrm{in}}=
\overline{\mathsf F}_p^\mathsf T\mathbf1.
```

Then the drift can be computed by the matrix formula

```math
m_{p,r}=
X^\mathsf T
\left(
d_{\mathrm{in}}-d_{\mathrm{out}}
\right).
```

No route enumeration is needed.

# 5. Exact quadratic variation as a Dirichlet matrix

The raw quadratic tensor is

```math
Q_{p,r}=
\sum_{v,w}
\overline{\mathsf F}_p(v,w)
\Delta X_{vw}\Delta X_{vw}^\mathsf T.
```

Let the outgoing and incoming degree matrices be

```math
D_{\mathrm{out}}=
\mathrm{diag}(d_{\mathrm{out}}),
\qquad
D_{\mathrm{in}}=
\mathrm{diag}(d_{\mathrm{in}}).
```

Expanding the squared differences gives

```math
Q_{p,r}=
X^\mathsf T
\left[
D_{\mathrm{out}}
+
D_{\mathrm{in}}-
\overline{\mathsf F}_p-
\overline{\mathsf F}_p^\mathsf T
\right]
X.
```

The identity is a finite Dirichlet-form formula.

The centered covariance is

```math
C_{p,r}=
Q_{p,r}-
m_{p,r}m_{p,r}^\mathsf T.
```

For two cylinder observables $F_\varphi,F_\psi$,

```math
\Gamma_{G,p,r}(F_\varphi,F_\psi)=
\frac12
\sum_{v,w}
\overline{\mathsf F}_p(v,w)
\Delta F_\varphi(v,w)
\Delta F_\psi(v,w).
```

The matrix is the finite-DAG analogue of the continuum carré du champ.

# 6. Higher moments without enumerating paths

The third tensor is

```math
M_{p,r}^{(3)}=
\sum_{v,w}
\overline{\mathsf F}_p(v,w)
\Delta X_{vw}^{\otimes3}.
```

More generally,

```math
M_{p,r}^{(q)}=
\sum_{v,w}
\overline{\mathsf F}_p(v,w)
\Delta X_{vw}^{\otimes q}.
```

All Kramers-Moyal coefficients are edge sums weighted by
$\overline{\mathsf F}_p$.

# 7. Local coefficients rather than only global averages

The global tensor gives the average regime; a state-dependent continuum
operator requires local conditional coefficients.

For a node $v$ with $r_k(v)>0$, define

```math
b_{G,r,k}(v)=
\frac1{a_G}
\sum_w
P_k(v,w)
\left[
X_r(w)-X_r(v)
\right],
```

and

```math
a_{G,r,k}(v)=
\frac1{a_G}
\sum_w
P_k(v,w)
\Delta X_{vw}\Delta X_{vw}^\mathsf T.
```

The finite generator acting on a cylinder function $F$ is

```math
(\mathcal G_{G,r,k}F)(x_{G,r}(v))=
\frac1{a_G}
\sum_wP_k(v,w)
\left[
F(x_{G,r}(w))-F(x_{G,r}(v))
\right].
```

For a smooth polynomial cylinder, Taylor expansion gives

```math
\mathcal G_{G,r,k}F=
b_{G,r,k}^i\partial_iF
+
\frac12a_{G,r,k}^{ij}
\partial_i\partial_jF
+
\text{higher terms}.
```

The local drift and diffusion fields are thus directly computable at every
node and remaining horizon.

# 8. The intrinsic time normalization

Because the bounded system definition contains no external clock, the
continuum time scale is determined only up to a global multiplicative
constant.

A coordinate-independent normalization can nevertheless be defined using the
canonical metric $d_r$ on $\mathcal Y_r$:

```math
a_{G,p,r}=
\sum_{v,w}
\overline{\mathsf F}_p(v,w)
d_r\!\left(
x_{G,r}(v),x_{G,r}(w)
\right)^2.
```

The quantity is the mean squared profile displacement per primitive channel.

The local diffusive regime requires

```math
a_{G_n,p_n,r}\to0.
```

Continuum time is then

```math
\tau=j,a_{G_n,p_n,r}.
```

With this normalization, the average intrinsic quadratic variation per unit
continuum time equals one.

Changing the normalization of the base metric rescales time globally but does
not change the dimensionless geometry, drift directions, anisotropy, tail
exponents or spectral ratios.

The absence of an external clock leaves this residual global rescaling
undetermined.

# 9. Label invariance

Let $S$ be a permutation matrix representing a relabeling of the nodes.

Under this relabeling,

```math
A\mapsto SAS^\mathsf T,
\qquad
r_k\mapsto Sr_k,
\qquad
\ell_j\mapsto S\ell_j,
```

and

```math
\overline{\mathsf F}_p\mapsto
S\overline{\mathsf F}_pS^\mathsf T,
\qquad
X\mapsto SX.
```

Consequently,

```math
m_{p,r}
\mapsto
X^\mathsf TS^\mathsf T
S(d_{\mathrm{in}}-d_{\mathrm{out}})=
m_{p,r},
```

and similarly

```math
Q_{p,r}\mapsto Q_{p,r}.
```

Thus $m_{p,r}$, $Q_{p,r}$, and $C_{p,r}$ are exact isomorphism invariants.

The coefficient extraction is invariant under the topological ordering used
to encode the DAG.

# 10. Avoiding a premature graph ensemble

These coefficients are defined per graph.

The bounded-system definition leaves the probability measure over
non-isomorphic DAGs unspecified. Two natural averages then differ:

## Equal unlabeled weighting

The equal-unlabeled average is

```math
\frac1{|\mathfrak G_n|}
\sum_{[G]\in\mathfrak G_n}
\mathcal O(G).
```

Each physical isomorphism class receives equal weight.

## Uniform labeled weighting

The corresponding labeled average is

```math
\frac{
\sum_{[G]}
\frac{n!}{|\mathrm{Aut}(G)|}
\mathcal O(G)
}{
\sum_{[G]}
\frac{n!}{|\mathrm{Aut}(G)|}
}.
```

The measure comes from uniform counting of labeled adjacency structures.

Both measures are external sampling conventions. The canonical procedure is
therefore to compute coefficients per isomorphism class first and then study:

* universality across graph sequences;
* conditional distributions at fixed height or density;
* equal-class and automorphism-weighted ensemble summaries separately.

Keeping the ensembles separate prevents a sampling convention from being
mistaken for derived dynamics.

# 11. Projective refinement before diagonal selection

A diagonal sequence $r_n\to\infty$ is computationally useful. The analysis can
first be formulated projectively at each fixed refinement depth.

For every fixed $r$, the profile space $\mathcal Y_r$ is compact. Let

```math
\pi_{r+1,r}:\mathcal Y_{r+1}\to\mathcal Y_r
```

forget the final refinement layer.

The infinite profile space is the inverse limit

```math
\mathcal Y_\infty=
\varprojlim_r\mathcal Y_r.
```

A point is a compatible sequence

```math
x=(x_0,x_1,x_2,\ldots),
\qquad
\pi_{r+1,r}(x_{r+1})=x_r.
```

Because it is a closed subset of a product of compact spaces,

```math
\mathcal Y_\infty
\text{ is compact}.
```

Cylinder functions depend on only finitely many refinement levels. The safer
order is therefore

```math
n,p\to\infty
\text{ at fixed }r,
\qquad
\text{then }r\to\infty.
```

The projective-limit route postpones the additional estimate

```math
r_{\mathrm{stab}}(n)=o(n)
```

until a diagonal sequence is required.

The exhaustive eight-node computation shows that stabilized refinement
resolves all $20{,}286{,}025$ non-isomorphic DAGs, while one round has $509$
collision classes. The first separation round of each collision class is the
finite datum needed to estimate the growth of the projective coordinate
depth.

# 12. Fixed-(r) continuum convergence theorem

Take a sequence

```math
(G_n,p_n)
```

with

```math
|V(G_n)|\to\infty,
\qquad
p_n\to\infty.
```

Fix $r$.

Let the finite route-profile process be

```math
X_n(\tau)=
x_{G_n,r}
\left(
V_{\lfloor\tau/a_n\rfloor}
\right),
```

where

```math
a_n=a_{G_n,p_n,r}.
```

Suppose:

1. Vanishing jumps: $\sup_{\text{route-relevant }e}d_r(x(s(e)),x(r(e)))\to0$.
2. Cylinder generator convergence: For every polynomial cylinder $F$,
   $\mathcal G_nF\to\mathcal GF$ uniformly on the relevant embedded states.
3. Quadratic convergence: $\Gamma_n(F,G)\to\Gamma(F,G)$.
4. Lindeberg condition:
   $\frac1{a_n}\mathbb E\left[d_r(\Delta X_n)^2 \mathbf1_{\{d_r(\Delta X_n)>\varepsilon\}} \right]\to0$.

5. Bulk plateau: the coefficients become independent of the normalized route
   position away from both horizon boundaries.
6. Uniqueness: the martingale problem for $\mathcal G$ on the cylinder core is
   unique.

It follows that

```math
X_n\Rightarrow X
```

in the path space over $\mathcal Y_r$, where $X$ has generator $\mathcal G$.

Compact containment is substantially simplified because $\mathcal Y_r$ is
already compact.

# 13. Passing to the full profile limit

Suppose every $r$ has a limiting process

```math
X^{(r)}
```

on $\mathcal Y_r$, and the limits are projectively consistent:

```math
\pi_{r+1,r}(X^{(r+1)})
\overset{d}=X^{(r)}.
```

Then there exists a process

```math
X^{(\infty)}
```

on $\mathcal Y_\infty$ having these finite-refinement projections, provided the
consistency holds at the level of path-space laws so that the Kolmogorov
extension applies on $\mathcal Y_\infty=\varprojlim_r\mathcal Y_r$. Consistency
of one-dimensional distributions alone does not supply it.

Its generator is determined on cylinder functions by

```math
\mathcal G_\infty
(F\circ\pi_r)=
(\mathcal G_rF)\circ\pi_r.
```

The projective limit defines the infinite-profile continuum operator.

The construction does not require embedding the entire infinite profile
manifold into $\mathbb R^d$.

Finite cylinder observables define and compute the operator, which the
projective limit assembles.

# 14. Literature relation

Section 11 orders the limits as $n,p\to\infty$ at fixed $r$, followed by
$r\to\infty$, in place of a diagonal sequence satisfying
$r_{\mathrm{stab}}(n)=o(n)$. Two results make that order forced rather than
convenient. M. Fürer, *Weisfeiler-Lehman refinement requires at least a linear
number of iterations*, in Automata, Languages and Programming, Lecture Notes in
Computer Science 2076, Springer, 2001, 322-333, exhibits for each fixed
dimension pairs on which refinement requires a linear number of iterations, and
the best available general upper bound at dimension two is the superlinear
$O(n\log n)$ of M. Lichter, I. Ponomarenko, and P. Schweitzer, *Walk refinement,
walk logic, and the iteration number of the Weisfeiler-Leman algorithm*, in 2019
34th Annual ACM/IEEE Symposium on Logic in Computer Science, IEEE, 2019, 1-13,
arXiv:1905.03008. No bound of the form $o(n)$ follows from either.

Both concern undirected graphs. Realization of Fürer's pairs inside the
acyclic-digraph class used here, together with the $O(n\log n)$ bound on
that class, remains open.

The convergence statement of section 12 is an instance of the scheme in
S. N. Ethier and T. G. Kurtz, *Markov Processes: Characterization and
Convergence*, Wiley, 1986, Chapter 4, which combines generator convergence on a
core with compact containment and uniqueness of the limiting martingale problem.
Hypothesis 2 of section 12 is the generator convergence and hypothesis 6 the
uniqueness requirement, both for the cylinder core on $\mathcal Y_r$, and the
compactness of $\mathcal Y_r$ established in section 11 is what makes the
compact-containment requirement automatic. Uniqueness for $\mathcal G$ on that
core enters as Hypothesis 6.

The count $20{,}286{,}025$ quoted in section 11 is the number of acyclic
digraphs on eight unlabeled nodes, recorded as Sequence A003087, On-Line
Encyclopedia of Integer Sequences; the counting theory for unlabeled graphs and
digraphs is developed in F. Harary and E. M. Palmer, *Graphical Enumeration*,
Academic Press, 1973. The collision count $509$ quoted beside it comes from the
computation reported there.
