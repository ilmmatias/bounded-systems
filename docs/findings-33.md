# 1. Normalized Green-profile space

Fix a root $o$, a weight $t>0$, the reachable node set $V_o$, and finite Green values $G_t(o,x)>0$.

For every reachable node $x$, define its normalized Green profile

```math
\kappa_x(v)=
K_t(v,x)=
\frac{G_t(v,x)}{G_t(o,x)}.
```

If $d(o,v)$ is the shortest path length from $o$ to $v$, prefixing a shortest path $o\to v$ gives

```math
G_t(o,x)\ge t^{d(o,v)}G_t(v,x).
```

The resulting bound is

```math
0\le \kappa_x(v)\le t^{-d(o,v)}.
```

Define the compact profile product

```math
\mathcal P_t=
\prod_{v\in V_o}
[0,t^{-d(o,v)}].
```

The node map is

```math
\iota_t:V_o\longrightarrow\mathcal P_t,
\qquad
x\longmapsto\kappa_x.
```

The weighted Martin compactification is the closure

```math
\mathcal M_t=
\overline{\iota_t(V_o)}
\subseteq\mathcal P_t.
```

Martin compactification embeds points by their normalized Green kernels and takes the closure.

# 2. Finite-observation spaces

For a finite node set

```math
F\Subset V_o,
```

let

```math
\mathrm{pr}_F:
\mathcal P_t
\longrightarrow
\prod_{v\in F}[0,t^{-d(o,v)}]
```

be coordinate restriction.

The finite-observation profile space is

```math
\mathcal M_{t,F}=
\overline{
\mathrm{pr}_F\bigl(\iota_t(V_o)\bigr)
}.
```

$\mathcal M_{t,F}$ comprises all limits of observations at only the nodes in $F$.

If $F\subseteq F'$, restriction gives a continuous surjection

```math
r_{F',F}:
\mathcal M_{t,F'}
\longrightarrow
\mathcal M_{t,F}.
```

The finite profile spaces form an inverse system.

# 3. Finite-observation reconstruction theorem

There is a canonical homeomorphism

```math
\mathcal M_t
\cong
\varprojlim_{F\Subset V_o}
\mathcal M_{t,F}.
```

## Proof

Every $h\in\mathcal M_t$ determines the compatible family

```math
\bigl(h|_F\bigr)_F.
```

The map into the inverse limit is injective because profiles agreeing on every finite subset agree at every node.

Conversely, suppose

```math
(y_F)_F
\in
\varprojlim_F\mathcal M_{t,F}.
```

Compatibility determines one function

```math
y:V_o\to[0,\infty)
```

whose restriction to $F$ is $y_F$.

A basic product neighborhood of $y$ depends on only finitely many coordinates, say those in $F$. Since

```math
y_F\in
\overline{
\mathrm{pr}_F(\iota_t(V_o))
},
```

that neighborhood contains the finite projection of a normalized Green column, every basic neighborhood of $y$ intersects $\iota_t(V_o)$, so

```math
y\in\overline{\iota_t(V_o)}=\mathcal M_t.
```

Inverse limits provide the natural setting for reconstructing compact spaces from compatible finite-coordinate data.

# 4. Role of the closures

Using the raw images instead

```math
Y_{t,F}=
\mathrm{pr}_F(\iota_t(V_o)),
```

The formula

```math
\mathcal M_t
\stackrel{?}{=}
\varprojlim_FY_{t,F}
```

can fail.

A limiting coordinate value may be approximated arbitrarily well without being attained by any actual node. It belongs to

```math
\overline{Y_{t,F}}
```

but not necessarily to $Y_{t,F}$.

Thus the corrected formula is

```math
\mathcal M_t=
\varprojlim_F\overline{Y_{t,F}}.
```

If every finite profile image is closed, for example, in certain finite or discrete situations, the closures can be omitted.

# 5. Collapse and completion are different operations

The two equivalence relations are distinct.

Suppose $X_t$ is a set of Martin-regular tail ends and

```math
\Phi_t:X_t\to\mathcal P_t,
\qquad
\Phi_t(\xi)=h_\xi.
```

Then there are two separate steps:

```math
X_t
\xrightarrow{\text{profile quotient}}
\Phi_t(X_t)
\xrightarrow{\text{closure}}
\overline{\Phi_t(X_t)}.
```

Martin equivalence defines the profile quotient by identifying histories satisfying $h_\xi=h_\eta$; this quotient removes route information.

## Profile completion

The compactification adds limiting profiles that need not come from a regular history.

It does not identify existing points; it adjoins new ones.

```math
\text{collapse}
\neq
\text{completion}.
```

The first is measured by Martin defect fibers.

The second is measured by the difference

```math
\overline{\Phi_t(X_t)}
\setminus
\Phi_t(X_t).
```

# 6. Not every Martin point must come from one ray

A Martin boundary point is a net limit of normalized Green columns of nodes.

It need not be generated by:

* one literal infinite path;
* one Martin-regular ray;
* or even one countable sequence.

Consequently, the closure of regular ray profiles can be smaller than the full Martin compactification:

```math
\overline{\Phi_t(X_t)}
\subseteq
\mathcal M_t.
```

Equality requires an additional ray-generation theorem.

The bounded system definition alone does not provide one, especially with infinite branching or moving-endpoint escape.

So the primary node compactification remains

```math
\mathcal M_t=
\overline{\{\kappa_x:x\in V_o\}},
```

while regular rays supply a distinguished subset of its boundary.

# 7. The finite-observable algebra

For finite $F$, let

```math
\mathcal A_F=
\left\lbrace f\circ\mathrm{pr}_F: f\in C(\mathcal M_{t,F}) \right\rbrace
\subseteq C(\mathcal M_t).
```

These are continuous observables depending on only finitely many node Green ratios.

If $F,F'$ are finite, sums and products of an $F$-observable and an $F'$-observable depend only on

```math
F\cup F'.
```

Equivalently,

```math
\mathcal A_{\mathrm{fin}}=
\bigcup_{F\Subset V_o}\mathcal A_F
```

is a unital self-adjoint algebra.

It separates points of $\mathcal M_t$: two different profiles differ at some node $v$, and the coordinate observable at $v$ distinguishes them.

By Stone-Weierstrass,

```math
\overline{\mathcal A_{\mathrm{fin}}}^{\|\cdot\|_\infty}=
C(\mathcal M_t).
```

Every continuous node-level Martin observable is uniformly approximable by observables involving only finitely many nodes.

Finite node observations do not recover route history; they recover all continuous information on the already-compressed node compactification.

# 8. Exact algebraic defect intersection

Return to a set $X_t$ of Martin-regular ends.

For finite $F\Subset V_o$, define

```math
\xi\sim_F\eta
\iff
h_\xi(v)=h_\eta(v)
\quad
\forall v\in F.
```

Define $\mathfrak D_F$ by

```math
\mathfrak D_F=
\mathrm{span}
\{
\delta_\xi-\delta_\eta:
\xi\sim_F\eta
\}
\subseteq k^{(X_t)}.
```

Let full Martin equivalence be

```math
\xi\sim_M\eta
\iff
h_\xi=h_\eta,
```

with defect module

```math
\mathfrak D_M=
\mathrm{span}
\{
\delta_\xi-\delta_\eta:
\xi\sim_M\eta
\}.
```

It follows that

```math
\mathfrak D_M=
\bigcap_{F\Subset V_o}
\mathfrak D_F.
```

## Proof

The inclusion

```math
\mathfrak D_M\subseteq\mathfrak D_F
```

is immediate.

For the reverse inclusion, take

```math
\mu=\sum_{i=1}^m c_i\delta_{\xi_i}
```

in every $\mathfrak D_F$.

Its support contains only finitely many histories. For each pair with different full profiles, choose a node distinguishing them; the union of these nodes is a finite set $F_0$.

On the finite support of $\mu$, the $F_0$-equivalence classes are exactly the full Martin-equivalence classes.

Since

```math
\mu\in\mathfrak D_{F_0},
```

The sum of its coefficients in every full Martin class is zero. Hence

```math
\mu\in\mathfrak D_M.
```

The finite-support condition is essential to this exact argument.

# 9. Dual observable interpretation

The algebraic dual of $k^{(X_t)}$ is the space of all functions

```math
a:X_t\to k.
```

The annihilator of $\mathfrak D_F$ is

```math
\mathfrak D_F^\perp=
\{
a:a(\xi)=a(\eta)
\text{ whenever }\xi\sim_F\eta
\}.
```

These functions factor through the finite profile quotient

```math
X_t/\!\sim_F.
```

Likewise,

```math
\mathfrak D_M^\perp=
\{
a:a\text{ is constant on full Martin fibers}
\}.
```

The two sides are exact dual shadows:

```math
\begin{array}{c|c}
\text{Defect module}&\text{Observable space}\\
\hline
\mathfrak D_F&
\text{distinctions invisible on }F\\
\mathfrak D_F^\perp&
\text{observables determined by }F\\
\mathfrak D_M&
\text{distinctions invisible to every node}\\
\mathfrak D_M^\perp&
\text{all functions of the full node profile}
\end{array}
```

# 10. Canonical observation-depth filtration

The directed family of all finite subsets is complete but unwieldy.

There is also a canonical one-parameter filtration relative to the root.

The radius-$n$ observation set is

```math
B_n(o)=
\{v\in V_o:d(o,v)\le n\}.
```

No finiteness of $B_n(o)$ is assumed.

Define observation equivalence at depth $n$ by

```math
\xi\sim_n\eta
\iff
h_\xi(v)=h_\eta(v)
\quad
\forall v\in B_n(o),
```

and let

```math
\mathfrak D_n=
\mathrm{span}
\{
\delta_\xi-\delta_\eta:
\xi\sim_n\eta
\}.
```

It follows that

```math
\mathfrak D_{n+1}\subseteq\mathfrak D_n
```

and

```math
\mathfrak D_M=
\bigcap_{n\ge0}\mathfrak D_n.
```

Every reachable node has finite compositional distance from $o$, so agreement on every $B_n(o)$ is exactly agreement at every reachable node.

The filtration uses only the graph’s intrinsic compositional depth.

# 11. First separation depth

For two regular ends, define

```math
s_t(\xi,\eta)=
\min
\left\lbrace d(o,v): h_\xi(v)\ne h_\eta(v) \right\rbrace,
```

when their profiles differ.

If their node profiles are identical, set

```math
s_t(\xi,\eta)=\infty.
```

It follows that

```math
\xi\sim_n\eta
\iff
s_t(\xi,\eta)>n.
```

The observation threshold is

```math
s_t(\xi,\eta)=
\text{first compositional depth at which a node observable separates them}.
```

For a unique-route rooted tree, this is the depth at which the rays first diverge. Two histories in a diamond followed by a common tail have $s_t=\infty$ because no node Green profile distinguishes them, and every pair in complete layered mixing likewise has $s_t=\infty$.

# 12. Exact defect layer at depth $n$

Let $C_n=X_t/\!\sim_n$ be the set of depth-$n$ profile classes.

There is a refinement map

```math
\rho_n:C_{n+1}\to C_n.
```

For a coarse class $c\in C_n$, let

```math
\rho_n^{-1}(c)
```

be the collection of finer classes into which it splits at depth $n+1$.

Then there is a canonical exact sequence

```math
0
\longrightarrow
\mathfrak D_{n+1}
\longrightarrow
\mathfrak D_n
\longrightarrow
\bigoplus_{c\in C_n}
\widetilde{k}^{(\rho_n^{-1}(c))}
\longrightarrow
0.
```

The last map records, for a zero-total combination in a coarse class, the total coefficient in each finer subclass.

Its kernel consists exactly of combinations already having zero total inside every finer class, namely $\mathfrak D_{n+1}$.

```math
\mathfrak D_n/\mathfrak D_{n+1}
\cong
\bigoplus_{c\in C_n}
\widetilde{k}^{(\rho_n^{-1}(c))}.
```

The quotient records distinctions first visible at observation depth $n+1$.

# 13. Finite partition count

If $C_n$ and $C_{n+1}$ are finite, then

```math
\dim
\left(
\mathfrak D_n/\mathfrak D_{n+1}
\right)=
\sum_{c\in C_n}
\left(
|\rho_n^{-1}(c)|-1
\right).
```

This gives

```math
\dim
\left(
\mathfrak D_n/\mathfrak D_{n+1}
\right)=
|C_{n+1}|-|C_n|.
```

The number of newly distinguishable profile directions is exactly the increase in the number of observation classes.

For infinite class sets, cardinal subtraction is not canonical, so the direct-sum module remains the correct invariant.

# 14. Observation refinement diagram

The profile classes form a canonical refinement diagram:

* level $n$ consists of the classes in $C_n$;
* an edge joins $c'\in C_{n+1}$ to $c\in C_n$ when $\rho_n(c')=c$.

A history determines a compatible descending chain of profile classes

```math
c_0\leftarrow c_1\leftarrow c_2\leftarrow\cdots.
```

Two histories have the same full Martin profile exactly when they determine the same branch through every level.

```math
\text{finite observation}
\longrightarrow
\text{successive profile refinement}
\longrightarrow
\text{full node asymptotic profile}.
```

The defect quotient at each level records the new branch splitting at that level.

# 15. Completed and realized branches

Realized branches come from actual regular histories. Completed branches are coherent limits in the compact finite-profile spaces

```math
\mathcal M_{t,B_n(o)}.
```

A completed branch may fail to come from one actual history.

Therefore the inverse-limit completion contains realized profile branches and may also contain generalized coherent branches.

The construction parallels completion of finite paths by boundary points, with normalized Green observations replacing prefixes.

# 16. Special zero-dimensional case

If all finite profile spaces are finite and discrete, then

```math
\mathcal M_t
\cong
\varprojlim_F\mathcal M_{t,F}
```

is a profinite space.

In that case:

* clopen cylinder sets come from finite node observations;
* every profile is determined by a compatible system of finite discrete profiles;
* the finite-observable algebra is the locally constant algebra;
* its uniform completion is $C(\mathcal M_t)$.

Inverse limits of finite discrete spaces are exactly the standard profinite construction.

The general Martin profile spaces need not be discrete, so the unrestricted construction is compact inverse-limit rather than necessarily profinite.
