# 1. The critical profile already fixes the gauge temperature

We had

```math
\mathcal A_+h=\lambda h,
\qquad
\lambda=R^{-2}.
```

Set

```math
\beta=\log\lambda=-2\log R.
```

The critical cylinder weights are

```math
\mu_h[p]=
\lambda^{-|p|}
\frac{h(r(p))}{h(o)}=
e^{-\beta|p|}
\frac{h(r(p))}{h(o)}.
```

For the gauge action

```math
\alpha_t(L_p)=e^{it|p|}L_p,
```

define, on the rooted analytic monomials,

```math
\omega_h(L_pL_q^\ast)=
\delta_{p,q},
e^{-\beta|p|}
\frac{h(r(p))}{h(o)}.
```

Since

```math
\alpha_{i\beta}(L_p)=e^{-\beta|p|}L_p,
```

the elementary KMS relation becomes

```math
\omega_h(L_pL_q^\ast)=
\omega_h\!\left(
L_q^\ast\alpha_{i\beta}(L_p)
\right).
```

The harmonic equation ensures consistency at every regular node:

```math
\sum_{e:s(e)=r(p)}
\omega_h(L_{pe}L_{pe}^\ast)=
\omega_h(L_pL_p^\ast).
```

Subject to the usual representation and summability hypotheses, the Martin/harmonic boundary profile is also a gauge-equilibrium state; the correspondence among graph gauge dynamics, adjacency eigenvectors and KMS states is standard in graph operator algebras.

So the critical radius has already produced the thermodynamic scaling

```math
\beta_c=\log\lambda=-2\log R.
```

That was encoded in the path growth.

# 2. The intrinsic tangent-noise space

At a critical profile $h$, tangent scores satisfy

```math
P_h\phi=\phi.
```

The local quadratic form is

```math
g_v(\phi,\psi)=
\sum_{e:s(e)=v}
P_h(e\mid v)
\Delta_e\phi,
\Delta_e\psi,
```

where

```math
\Delta_e\phi=
\phi(r(e))-\phi(v).
```

After quotienting the null directions and completing, this gives a local tangent Hilbert space

```math
\mathfrak t_{h,v}.
```

Let $j_e\in\mathfrak t_{h,v}$ be the Riesz representative of the edge increment functional:

```math
\langle j_e,\phi\rangle_h=
\Delta_e\phi.
```

Because the metric itself was defined by the quadratic variation,

```math
\begin{aligned}
\langle\phi,\psi\rangle_h
&=
\sum_eP_h(e\mid v)
\langle j_e,\phi\rangle_h
\langle j_e,\psi\rangle_h.
\end{aligned}
```

Equivalently,

```math
\sum_{e:s(e)=v}
P_h(e\mid v),
j_e\otimes j_e=
I_{\mathfrak t_{h,v}}.
```

In the metric generated by the local quadratic variation, the one-step covariance operator is exactly the identity.

The quadratic regime is intrinsically isotropic relative to the system-generated metric, not an external Euclidean metric.

# 3. The Gaussian tangent closure

Along a derived $P_h$-history, the score process

```math
M_n^\phi=\phi(X_n)
```

is a martingale, with bracket

```math
\langle M^\phi,M^\psi\rangle_N=
\sum_{k=0}^{N-1}
g_{X_k}(\phi,\psi).
```

Under the usual Lindeberg condition, vanishing maximal increments and convergence of the normalized bracket, the rescaled tangent martingale converges by the standard martingale central-limit mechanism to a Gaussian field with this quadratic form as covariance.

The second-order profile regime therefore lives naturally on the symmetric Fock space

```math
\Gamma_s(\mathfrak t_h)=
\bigoplus_{n\ge0}
\mathrm{Sym}^n\mathfrak t_h.
```

Let

```math
N_h=
d\Gamma(I_{\mathfrak t_h})
```

be its number operator:

```math
N_h\big|_{\mathrm{Sym}^n\mathfrak t_h}=
nI.
```

The Gaussian Ornstein–Uhlenbeck semigroup is

```math
T_\tau^{\mathrm{diff}}=
e^{-\tau N_h}.
```

The corresponding reversible phase evolution is

```math
U_t^{\mathrm{prof}}=
e^{-itN_h}.
```

Ornstein–Uhlenbeck evolution via second quantization and the Fock number operator are standard in Gaussian/Fock analysis.

# 4. From route Fock space to profile Fock space

The original resolved path space is graded:

```math
\mathcal H_G=
\bigoplus_{n\ge0}\mathcal H_n,
\qquad
\mathcal H_n=\ell^2(\mathsf P_n(G)).
```

Its gauge number operator is

```math
N_G\big|_{\mathcal H_n}=nI.
```

For a path

```math
p=e_n\cdots e_1,
```

define its quadratic profile image formally by

```math
\mathscr S_h\xi_p=
\mathrm{Sym}
\left(
\sqrt{P_h(e_1\mid v_0)},j_{e_1}
\otimes\cdots\otimes
\sqrt{P_h(e_n\mid v_{n-1})},j_{e_n}
\right).
```

Here

```math
v_0\xrightarrow{e_1}v_1
\xrightarrow{e_2}\cdots
\xrightarrow{e_n}v_n.
```

This map:

* forgets some ordered route information through symmetrization;
* forgets route directions invisible to the tangent increments;
* retains the homogeneous degree $n$.

Therefore, regardless of whether it is injective or isometric,

```math
N_h\mathscr S_h=
\mathscr S_hN_G.
```

Consequently,

```math
e^{-zN_h}\mathscr S_h=
\mathscr S_h e^{-zN_G}
```

for every $z$ for which the exponential is defined.

This is the precise bridge:

```math
\text{route gauge degree}
\longrightarrow
\text{profile-chaos degree}.
```

The kernel of $\mathscr S_h$ comprises route information invisible to the local quadratic profile regime, including route defects, and can be larger when distinct edge histories produce identical tangent increments.

```math

```

```math
H_{\mathrm{gauge}}=N_h.
```


on the visible quadratic profile sector.

This follows from:

# 6. Complex time

Since $N_h\ge0$ is self-adjoint, define

```math
\mathscr T(z)=e^{-zN_h},
\qquad
\Re z\ge0.
```

For real positive $z=\tau$,

```math
\partial_\tau\Psi=
-N_h\Psi,
```

which is the profile diffusion/Ornstein–Uhlenbeck equation.

For imaginary $z=it$,

```math
\Psi(it)=e^{-itN_h}\Psi(0),
```

and therefore

```math
i\partial_t\Psi=
N_h\Psi.
```

Thus the dissipative and reversible equations are two boundary directions of the same holomorphic evolution:

```math
\partial_z\Psi(z)=
-N_h\Psi(z).
```

On the $n$-th chaos sector,

```math
\Psi_n(z)=e^{-nz}\Psi_n(0).
```

So:

```math
\Psi_n(\tau)=e^{-n\tau}\Psi_n(0)
```

along the diffusive axis, while

```math
\Psi_n(it)=e^{-int}\Psi_n(0)
```

along the unitary axis.

The exact same compositional degree $n$ controls:

* exponential damping of fluctuations;
* phase rotation of amplitudes.

# 7. Incorporating the critical KMS scaling

The raw gauge generator is $N_h$, but the critical state naturally rescales gauge time by

```math
\beta=\log\lambda.
```

Let $\kappa_D>0$ denote the chosen diffusion-time normalization. The coupled generator is

```math
\mathfrak A_{\mathrm{quad}}=
\kappa_DN_h+i\beta N_h=
(\kappa_D+i\beta)N_h.
```

Its evolution is

```math
\Psi_s=
e^{-s\mathfrak A_{\mathrm{quad}}}\Psi_0=
e^{-\kappa_DsN_h}
e^{-i\beta sN_h}\Psi_0.
```

Equivalently,

```math
\partial_s\Psi_s=
-(\kappa_D+i\beta)N_h\Psi_s.
```

Since

```math
\beta=\log\lambda=-2\log R,
```

we obtain

```math
\partial_s\Psi_s=
-\left(
\kappa_D-2i\log R
\right)N_h\Psi_s.
```

With unit quadratic-variation time,

```math
\kappa_D=1,
```

this becomes

```math
\partial_s\Psi_s=
-\left(
1+i\log\lambda
\right)N_h\Psi_s.
```

On homogeneous degree $n$,

```math
\Psi_n(s)=
\exp\left[
-n\kappa_Ds
-in(\log\lambda)s
\right]\Psi_n(0).
```

This is the closed equation of the quadratic critical regime.

Since the coefficient has positive real part, $(\kappa_D+i\beta)N_h$ is sectorial and generates a holomorphic contraction semigroup; more generally, the standard representation theorems associate closed sectorial forms with m-sectorial operators and holomorphic semigroups.

# 9. Third-order correction

The quadratic theory is the free regime; its first deviation can now be computed.

Write

```math
u_\varepsilon=
u+\varepsilon\phi
+\frac{\varepsilon^2}{2}\chi
+\frac{\varepsilon^3}{6}\zeta
+O(\varepsilon^4).
```

We already have

```math
(I-P_h)\phi=0
```

and

```math
(I-P_h)\chi=
\mathrm{Var}_{P_h}(\phi).
```

The third derivative of the log-sum-exp is the third centered cumulant. Therefore

```math
(I-P_h)\zeta=
3\,\mathrm{Cov}_{P_h}(\phi,\chi)
+
\kappa_{3,P_h}(\phi),
```

where locally

```math
\kappa_{3,P_h}(\phi)(v)=
\sum_eP_h(e\mid v)
\bigl(
\phi(r(e))-\phi(v)
\bigr)^3.
```

So the hierarchy begins:

```math
\begin{aligned}
\text{first order:}&\quad
(I-P_h)\phi=0,\\
\text{second order:}&\quad
(I-P_h)\chi=\kappa_2(\phi),\\
\text{third order:}&\quad
(I-P_h)\zeta
=3\mathrm{Cov}(\phi,\chi)+\kappa_3(\phi).
\end{aligned}
```

At fourth order, the fourth cumulant and quadratic combinations of $\chi$ enter.

# 10. Interactions beyond the Gaussian regime

In the profile-chaos representation, the quadratic term is diagonal in degree:

```math
N_h.
```

Higher cumulants create, annihilate or mix chaos degrees, so the full effective generator has the form

```math
\mathfrak A=
(\kappa_D+i\beta)N_h
+
V_3+V_4+\cdots,
```

where:

* $V_3$ is determined by local third cumulants;
* $V_4$ is determined by fourth cumulants and second-order contractions;
* higher $V_r$ encode progressively higher non-Gaussian route coherence.

The free critical regime is

```math
V_r=0
\qquad(r\ge3).
```

If the interaction form

```math
V=V_3+V_4+\cdots
```

is relatively form-bounded with respect to $N_h$ with sufficiently small relative bound, then

```math
(\kappa_D+i\beta)N_h+V
```

remains closed and sectorial, so the coupled evolution survives beyond the Gaussian approximation by sectorial-form perturbation theory.
